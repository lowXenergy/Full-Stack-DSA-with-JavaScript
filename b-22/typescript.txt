Why typescript?
JS work weridly with types. Js is loosely type.Js is little crazy abou types.
    String + number = String
    String - number = number or Nan //Not supported in ts.
    String * number = number
    Boolean + Boolean = number
    []+[]=String
    [1]+1=11(String)
    [1,2]+1=1,21(String)
    5+true=6(number)
    "5"+true=5true(String)
    {}+[]=[object object] or 0
    []==false=>true
To solve all these confussions we use typescript.

Types in ts => Primitive data types => string, number, boolean , array ,object, tuple , void , never.
Array = fixed type but not the length 
tuple = fixed size and type
void=> function not returning anything.
function greet(name:string: void{
    console.log("Hello"+name)
})
greet("cohort");

Simple error
function greet(name:string: string{
    return "Hello"+name
})
greet("cohort");

never function: function that never end.
function greet(name:string):never{
    throw new Error("something went wrong!")
}
greet("cohort")
